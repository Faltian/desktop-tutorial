01 / LÓGICA Y CÓDIGO{ }

Programación

Java · algoritmos · depuración

GitHub Copilot ↗Claude ↗
  • Copilot: consultar código y recibir sugerencias en un editor compatible.
  • Claude: pedir explicaciones, ejemplos pequeños y pistas adaptadas a tu nivel.
  • Idea de práctica: predecir qué hará un bucle antes de ejecutarlo.
Prompt para adaptar

Estoy en 1.º de DAW y aprendo Java. Te paso mi intento y el error: [pegar ambos]. Hazme una pregunta para localizar el fallo y dame una pista cada vez. Después propón un caso de prueba.

Comprueba → compila, prueba entradas diferentes y explica por qué funciona.

02 / DATOS Y RELACIONESSQL

Bases de datos

Modelado · SQL · MySQL / PostgreSQL

Claude ↗GitHub Copilot ↗
  • Claude: contrastar tu razonamiento sobre entidades, claves y relaciones.
  • Copilot: consultar y revisar SQL como código, aportando el esquema y el motor.
  • Idea de práctica: proponer datos ficticios que permitan comprobar un JOIN.
Prompt para adaptar

Uso [motor y versión]. Este es mi esquema y mi SELECT: [pegar]. Esperaba [resultado], pero obtengo [resultado real]. Ayúdame a entender el JOIN con tres filas ficticias por tabla.

Comprueba → usa una base de pruebas; revisa filas duplicadas, valores NULL y condiciones antes de modificar datos.

03 / ESTRUCTURA Y PRESENTACIÓN</>

Lenguajes de marcas

HTML · CSS · XML · accesibilidad

Claude ↗Figma Make ↗
  • Claude: pedir una revisión razonada de etiquetas, atributos y estructura.
  • Figma Make: explorar una interfaz mediante un prototipo interactivo.
  • Idea de práctica: comparar tu HTML con la estructura visual que quieres conseguir.
Prompt para adaptar

Revisa este HTML: [pegar]. Señala tres mejoras de semántica o accesibilidad y explica cada una. Quiero aplicarlas yo. Dime cómo comprobar el resultado en el navegador.

Comprueba → valida HTML/XML; prueba teclado, etiquetas de formularios y tamaños de pantalla. Un prototipo no garantiza accesibilidad.

04 / ORGANIZACIÓN DEL CÓDIGOgit

Entornos de desarrollo

Repositorios · Git · pruebas · documentación

Cursor ↗GitHub Copilot ↗
  • Cursor: entender la estructura de un proyecto y revisar cambios entre archivos.
  • Copilot: consultar código, preparar documentación y proponer pruebas.
  • Idea de práctica: crear un README a partir del funcionamiento real del proyecto.
Prompt para adaptar

Explica la estructura de este repositorio e indica qué archivos apoyan tu explicación. No modifiques nada. Propón tres pruebas y un esquema de README sin inventar funciones.

Comprueba → revisa el diff, ejecuta las pruebas y confirma que el README describe lo que existe.

05 / EQUIPOS Y REDES>_

Sistemas informáticos

Linux · Windows · redes · virtualización

Perplexity ↗Claude ↗
  • Perplexity: localizar documentación y comparar información con fuentes enlazadas.
  • Claude: pedir ejemplos y analogías para entender procesos, permisos o redes.
  • Idea de práctica: preparar una guía de diagnóstico para una máquina virtual.
Prompt para adaptar

Uso [sistema y versión] en una máquina virtual. Quiero entender [concepto]. Busca documentación oficial y propón una práctica breve. Explica cada comando y qué cambia antes de usarlo.

Comprueba → abre las fuentes originales y verifica sistema, versión y efectos de los comandos.

06 / DE LA IDEA AL PROTOTIPOUI

Proyectos y portfolio

Diseño · requisitos · planificación · presentación

Figma Make ↗Claude ↗
  • Figma Make: generar y explorar prototipos interactivos desde instrucciones.
  • Claude: descomponer una idea en requisitos, tareas y criterios de aceptación.
  • Idea de práctica: diseñar una web de reservas con datos ficticios.
Prompt para adaptar

Prototipa una web de reservas con datos ficticios: inicio, servicios y formulario. Incluye estados de error y confirmación y una vista móvil. Señala qué comportamientos son simulados.

Comprueba → separa el prototipo de las funciones reales: guardar datos, autenticar usuarios o enviar reservas necesita implementación y pruebas.

No hay coincidencias. Prueba otra palabra o selecciona «Todas».

Extra / El hábito que más te sirve

Convierte una respuesta en aprendizaje.

01. Da contexto

Tu nivel, objetivo, lenguaje o motor, versión y lo que ya has intentado.

02. Acota la ayuda

Pide una pista, una comparación o una revisión. Indica qué quieres hacer por tu cuenta.

03. Ponlo a prueba

Ejecuta, valida y consulta documentación. Una respuesta convincente puede contener errores.

04. Repite sin mirar

Cambia un dato o requisito. Si puedes resolverlo y explicarlo, comprueba que has entendido la idea.

Plantilla de prompt: «Estoy en [nivel]. Uso [tecnología y versión]. Quiero [objetivo]. He probado [intento]. Ayúdame con [tipo de ayuda] y dime cómo verificarlo».

¿Con cuál empezar?

Para entender: un asistente conversacional como Claude.

Para investigar: Perplexity y la documentación original.

Para trabajar con código: Copilot en un editor compatible o Cursor, según tu entorno.

Para explorar interfaces: Figma Make. Empieza por una tarea pequeña.

Antes de entregar una práctica

Comprueba las normas del profesor sobre IA y declara su uso cuando corresponda.

Trabaja con datos ficticios y elimina contraseñas, claves y datos personales de tus ejemplos.

Las funciones, integraciones y límites dependen del plan. Consulta las condiciones antes de pagar.

Tu criterio sigue siendo parte del trabajo.

Fuentes oficiales y alcance de la guía

Funciones consultadas el 7 de octubre de 2026. La distribución por asignaturas y los prompts son propuestas educativas, no una comparativa de rendimiento ni una prueba de todas las herramientas. Las asignaturas pueden variar según el centro y el curso.
